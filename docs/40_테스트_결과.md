## workerd 스모크 (wrangler dev + Node WebSocket 스크립트)

교사 로그인 200 / 오답 401 / 클래스 생성 / 입장 2명 / 교사·학생 WS 3개 / 학생의 `teacher:start` → "선생님만 할 수 있어요" / 팀장 지정 / 봇 추가 / 설정 변경 / 없는 팀 참여 → 한국어 오류 / 시작 → BUILD / 준비 → 1.5초 뒤 INTRO(alarm) / 7초 뒤 PLAN(alarm) / 확정 → BATTLE + 181프레임 구간 3개 소켓 방송 / 학생 소켓 종료 후 재접속 → 현재 BATTLE 뷰 + 구간 재수신. 모두 정상.

## 미수행 / 외부 대기

- 학생 30명 + 교사 실제 동시 접속, 100~200ms RTT·패킷 손실 조건, 20분 연속 워크플로 부하 — 실제 배포 환경에서 측정 필요. "30인 운영 검증 완료"라고 쓰지 않는다.
- 저사양 기기 fps, 태블릿 실기, 두 실제 기기 간 시각 차이(p95).
- DO 휴면/재시작 중 장애 주입, alarm 중복 주입 테스트(설계상 마감 기준 idempotent, 별도 주입 테스트는 미수행).
- 음악/효과음(미제작).
