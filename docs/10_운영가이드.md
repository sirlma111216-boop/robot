# 교사 운영 가이드

## 수업 전 준비 (5분)

1. 배포 주소 `/teacher` 에서 아이디 `teacher`, 비밀번호로 로그인한다. 비밀번호는 Cloudflare 비밀값 `TEACHER_PASSWORD` 이며 관리자가 정한다.
2. **클래스 만들기** → 6자리 코드와 QR이 나온다. 이 코드는 마지막 활동 후 24시간 뒤 자동 삭제된다(`CLASS_TTL_HOURS`).
3. 교실 화면에 QR을 띄운다. 학생은 QR 또는 `/join?code=코드` 로 들어와 닉네임만 입력한다. 이메일·실명은 받지 않는다.

## 팀 만들기

- 학생 명단에서 **팀장 지정**을 누르면 그 학생의 팀이 만들어지고 팀장은 자동으로 조종석에 앉는다. 팀은 최대 6개.
- 나머지 학생은 격납고 화면에서 원하는 팀 문을 눌러 들어간다. **남은 학생 자동 배정**을 누르면 가장 적은 팀부터 채운다. 팀 정원은 설정(기본 6명).
- 팀 안 역할: 팀장 = 조립 확정, 명령 확정. 팀원 = 부품 추천, 명령안 제안, 투표, 이모트.
- 팀장 교체: 팀 카드의 팀원 이름 옆 ★ 버튼. 팀장이 끊겨도 마감 때 팀원 제안 중 최다 득표안이 자동 사용된다.
- 학생 수가 적으면 **봇 팀**을 추가한다(쉬움/보통/어려움). 봇은 외부 API 없이 서버에서 계산한다.
- **입장 잠그기**로 늦은 입장을 막을 수 있다.

## 대회 진행

| 단계 | 기본 시간 | 학생이 하는 일 | 교사가 볼 것 |
|---|---|---|---|
| 조립 | 90초 | 팀장이 부품 5칸을 고르고 준비 완료 | 준비 팀 수 |
| 입장 | 7초 | 로봇 소개 | — |
| 전술 계획 (×6턴) | 25초 | 3개 명령 배치, 팀장 확정 | 확정 팀 수 |
| 전투 재생 | 9초 + 정리 4초 | 관람 | 점수 |
| 피트스톱 (2·3경기 전) | 40초 | 부품 자유 교체 | — |
| 시상대 | — | 결과 확인 | 다시 하기 |

- 전원 준비/확정 시 설정에 따라 1~2초 뒤 자동 진행된다("전원 준비 시 일찍 진행").
- 관제(🎓 버튼): **이 단계 바로 넘기기**(전투 재생 중 제외), **대회 종료**(현재 순위로 시상), **대기실로**(점수 초기화, 팀 유지).
- 교사 참가: 팀 카드의 **팀장으로 참가**. 기존 팀장은 팀원이 되고, **참가 그만**을 누르면 복귀한다. 참가 중에도 관제 권한은 유지되지만 상대 팀의 비공개 명령은 볼 수 없다.
- 학생 내보내기: 명단의 ✕ → 확인. 내보낸 학생의 세션은 즉시 끊긴다.

## 점수 규칙 (학생에게 설명할 때)

- 전투 끝에 가운데 왕관 원 안에 **혼자** 있으면 3점. 둘 이상이면 0점.
- 상대를 낙하 구역에 **밀어 넣으면** 2점(마지막 2.5초 안에 부딪힌 팀에게). 스스로 떨어지면 아무도 점수 없음.
- 고철 캡슐을 줍거나 자석으로 끌어오면 1점.
- 떨어지면 그 턴만 쉬고 다음 턴 출발 패드에서 복귀. 탈락 없음, 부품 파괴 없음.
- 한 경기 = 6턴 누적. 동점이면 왕관 점수 → 낙하 기여 → 공동 순위.
- 대회 우승 = 경기별 순위 포인트 합(6팀: 7·5·4·3·2·1, 4팀: 5·3·2·1, 2팀: 3·1).
- 전투가 끝나면 정비 드론이 모든 로봇의 속도를 25%로 줄인다(모두 동일).

## 문제 해결

- 학생 화면이 "연결 끊김": 자동 재접속된다. 새로고침해도 같은 자리로 돌아온다(토큰은 브라우저에 저장).
- 학생이 다른 기기로 바꿨다: 다시 입장하면 새 닉네임으로 새 자리가 생긴다. 이전 자리는 내보내기로 정리.
- 코드가 사라졌다: 관제실 홈에서 **기존 클래스 코드로 열기**. 24시간이 지나면 새로 만든다.
- 교사 비밀번호 변경: `npx wrangler secret put TEACHER_PASSWORD` (기존 교사 세션은 무효화된다).
- 클래스 즉시 삭제: 관제실에서 종료 후 `POST /api/class/코드/delete` (교사 로그인 필요) 또는 24시간 대기.

## 화면 요구

- 학생: 1024×768 이상 가로 화면 권장. 세로 폰은 가로 전환 안내가 뜬다.
- 교실 대형 화면: 교사 관전 화면(관제 닫힘)을 띄우면 전투 중계만 크게 보인다.
- 저사양 기기: 브라우저 콘솔에서 `localStorage.setItem('sc:reduceFx','1')` 로 흔들림·섬광을 줄이고, `localStorage.setItem('sc:lowend','1')` 로 저해상 배경을 쓴다(설정 UI는 후속).
